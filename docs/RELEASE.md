# 変更履歴

xyzzy 0.2.2.253（xyzzy-022 プロジェクト）から派生した後の変更点を、版ごとに
まとめます。新しいものが上です。

Lisp から見える動作の非互換は [incompatible-changes.md](incompatible-changes.md) に、
移行方法とともに記載しています。派生前の各版のリリースノートは
`release-note-0.2.2.2xx.md` です。

## 0.2.2.253.9 (2026-08-29)

  * フォントの設定を作り直しました

    用字ごとに分かれていた九つの枠を、符号位置だけでは描くフォントが決まらない
    五つ（欧文・和文・簡体字・繁体字・ハングル）に畳みました。まず代表フォントを
    選び、必要な用字だけ上書きする形になります。上書きの無い枠は、代表フォントが
    その字形を持っていればそれを、持っていなければ枠ごとの既定を使います。

    Lisp から見える鍵の変更は [incompatible-changes.md](incompatible-changes.md) に
    移行方法とともに記載しています。既にある `xyzzy.ini` の設定は引き継ぐので、
    見た目は変わりません。

  * 固定ピッチを名乗らないフォントも選べるようにしました

    Microsoft YaHei・Microsoft JhengHei・Malgun Gothic・BIZ UDゴシックのように
    欧字がプロポーショナルなフォントは、一覧に出ていませんでした。導入されて
    いないフォントが指定されているときは「見つかりません」と示します。

  * 升目に収まらない字の収め方を選べるようにしました

    字の形を保ったまま小さくするか、横に潰すか。新しい設定での既定は小さくする
    方です。

  * 游ゴシック・游明朝・メイリオ・Noto Sans JP を選ぶと文字が極端に小さくなるのを
    直しました

    升目の幅を `tmAveCharWidth` から決めていて、これらのフォントでは全角の送りに
    近い値が返るためでした。半角の送りを実測して決めるようにしました。

  * 印刷が画面と同じ組み方をするようになりました

    これまでは、プロポーショナルを名乗るフォントが一つでもあると升目を捨てて字ごと
    の幅で流していました。漢字とハングルのフォントは欧字がプロポーショナルなので、
    普通の設定では必ずそちらへ落ちます。同じ文書が画面と紙で違う位置に折り返り、
    行の長さも揃いませんでした。全角の字形を持つキリル・ギリシャなども、画面では
    二桁なのに紙では一桁で描かれていました。

    あわせて、印刷の「一行の文字数」をどのフォントでも指定できるようにしました。

  * 印刷のフォントの設定を、その印刷で使う代表フォント一つにしました

    用字ごとのフォントと、升目に収まらない字の扱いは共通設定に従います。今までの
    設定は、欧文の枠に指定していたフォントを引き継ぎます。

  * 二桁の字を、二桁ぶんの幅に対して中央へ寄せるようにしました

    枠のフォントが升目より狭いとき、全角の字が左へ寄っていました。

## 0.2.2.253.8 (2026-08-29)

  * 文字の桁数を Unicode の East Asian Width と、担当フォントの実測で決める
    ようにしました

    全角で描かれるのに 1 桁として扱われていた `× ÷ ± ° § ― ○ ■ ─ ♪ ・` などが
    2 桁になります。従来の文字集合に無い字（CJK 拡張 A の漢字、KS X 1001 に
    無いハングル、康熙部首、カタカナ拡張など）も同様です。

  * 鍵盤と IME から届く文字を、符号位置としてそのまま受け取るようにしました

    U+0080 から U+00FF が化けていました。日本語配列では `×` が `ﾗ` になり、
    `÷` のように CP932 の先頭バイトと値が重なる字は次の一打を巻き込んで外字に
    なっていました。

  * カーソルの幅を、符号の値ではなく画面の桁数で決めるようにしました

    U+0100 未満で 2 桁になる字の上で、字とカーソルの幅が食い違っていました。

## 0.2.2.253.1 (2026-08-25)

派生の起点です。内部表現を Unicode にして、Windows とのやりとりを W 系 API へ
移しました。

  * バッファの中の文字を Unicode の符号位置にしました

    文字集合ごとの内部コードをやめ、文字種の判定・全角半角の移し替え・
    クリップボード・印刷・Lisp のストリームまで符号位置で扱います。
    符号位置に写せない文字を対で表す仕掛けは廃止しました。

  * 内部コードの器を 32 ビットに広げ、BMP の外の文字を扱えるようにしました

    サロゲート対は 2 桁の 1 文字として扱い、カーソルは対の内側に入りません。
    キーを表す符号は Unicode の符号位置の外へ移しました。

  * Windows とのやりとりを UTF-16 に揃えました

    窓・メニュー・ダイアログ・タブバー・ツールチップ・クリップボード・IME・
    ファイル操作・コマンドラインが対象です。自前の窓は Unicode の窓として
    登録します。

  * 長いパスを扱えるようにしました。パスは UTF-8 のバイト列で持ち回ります

  * 設定を自前で読み書きし、UTF-8 で保つようにしました

  * 画面の DPI に追随するようにしました

    フォント・バー類・ダイアログ・アイコン・ルーラの寸法が対象です。
    バー類のフォントはシステムの設定に従います。

  * 文字幅を担当のフォントに合わせるようにしました

    曖昧な幅の文字は実測に合わせ、半角に固定する設定も用意しました。

  * 既定のフォントを、いまの Windows に入っているものにしました

  * ソースと同梱文書の文字符号を UTF-8 にし、ビルド環境を Visual Studio 2022 へ
    移行しました
